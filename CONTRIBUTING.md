# Contributing

Thanks for your interest in Folder Cover Wall.

## Development setup

1. Fork and clone the repository.
2. Run `npm install`.
3. Run `npm run dev` while developing.
4. Test the plugin in a temporary Obsidian vault.
5. Run `npm run build` before opening a pull request.

Please keep changes focused and avoid relying on undocumented Obsidian DOM internals when an official plugin API is available.

## Bug reports

Please include:

- Obsidian version.
- Operating system.
- Folder Cover Wall version.
- Active theme, if the problem is visual.
- Steps to reproduce.
- Screenshot or screen recording when useful.
