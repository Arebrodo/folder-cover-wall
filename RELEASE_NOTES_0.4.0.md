# Folder Cover Wall 0.4.0

Initial public release candidate by **Arebrodo**.

## Highlights

- Browse Obsidian folders as large cover cards in the left sidebar.
- Navigate nested folders without taking over the main editor pane.
- Keep notes and files accessible inside the selected folder.
- Choose folder covers from the current vault or from external folders on the computer.
- Automatically detect common `cover.*` filenames or use the first image in a folder.
- Generate a readable fallback cover when no image exists.
- Configure root folder, card width, aspect ratio, counts, and file visibility.

## Privacy note

External cover images are read locally and embedded into the plugin's `data.json`. They are not uploaded by the plugin.

## Release assets required by Obsidian

- `main.js`
- `manifest.json`
- `styles.css`
